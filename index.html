ESP32-S3 · ESP-NOW · USB HID

一套无线键鼠，
控制多台电脑。

kmlink 是一个基于 ESP32-S3 的无线 KVM。把你现有的 2.4G 键鼠接收器插在主板上，每台电脑插一块从板，按热键就能切换。被控电脑不装任何软件，也不需要联网。

工作原理

主板 A 读取接收器的键鼠数据，通过 ESP-NOW 发给当前选中的从板 B。B 在电脑上显示为标准 USB 键盘和鼠标。同一时刻只有一台电脑接收输入。

特点

零软件、免驱

被控电脑不装任何东西。公司管控电脑、工控机、BIOS 和装系统阶段都能用。

不依赖网络

板子之间点对点通信，不经过路由器，被控电脑可以完全断网。

最多 8 台

一块主板绑定 8 块从板，热键直达任意一台。

沿用现有键鼠

插上你正在用的 2.4G 接收器就行，不用换键盘鼠标。

切换不卡键

切换时自动松开旧电脑上的所有按键，热键本身不会漏到新电脑。

每对独立加密

每块从板与主板有单独的密钥，同屋多套设备互不干扰。

使用

1. 接线

板子原生 USB 口（GPIO19/20）CH340 口
主板 A插 2.4G 接收器供电
从板 B插被控电脑仅调试时使用

2. 配对（只需一次）

  1. 在主板 A 上按住 BOOT 3 秒以上（10 秒以内）后松开，打开 30 秒配对窗口。
  2. 给新的从板 B 上电，它会自动配对。已绑定过的 B 要重新配对：按住它的 BOOT 3 秒后松开。
  3. 配对结果保存在板子里，断电重启后自动恢复。多块 B 可以在同一个窗口里依次配对。

3. 切换电脑

操作效果
Ctrl + Alt + 1 … 8切到对应编号的电脑
Ctrl + Alt + `切到下一台在线的电脑（` 在 Esc 下方）
主板 A 短按 BOOT切到下一台在线的电脑

主板 A 的 BOOT 键

按住时长后松开动作
不到 1 秒切到下一台
3 到 10 秒打开配对窗口
10 秒以上清空所有绑定

固件

  • 出厂已烧录好固件，主板和从板到手即用，只需按上面的步骤配对一次。
  • 被控电脑上不需要安装驱动或软件，Windows、macOS、Linux 通用，BIOS 下也能用。
  • 固件更新：目前由卖家提供升级文件，后续版本将支持无线 OTA 升级。

当前限制

开发中。固件处于早期阶段，延迟、通信距离和接收器兼容性还在实测中。
  • 暂不支持多媒体键（音量、播放等）、横向滚轮和部分鼠标侧键。
  • 不支持 Boot 模式的少数接收器暂时无法使用。
  • CapsLock 等键盘指示灯状态不回传。
  • 被控电脑上原本使用 Ctrl+Alt+数字 的快捷键会被占用。
  • 没有剪贴板共享和跨屏移动，这两项请用软件 KVM。

路线图
